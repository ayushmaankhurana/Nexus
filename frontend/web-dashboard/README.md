# NEXUS Web Dashboard

## Primary User

Campus security staff.  
Secondary: admins, staff/faculty with restricted roles.

## Core Views

- **Student Lookup**
  - Search by roll number
  - Show:
    - Current/last-known location
    - Today’s schedule and attendance
    - Recent access events (entry, parking)
    - Reliability score and recent risk signals
    - Open incidents

- **Live Monitoring / Map**
  - View zones and buildings
  - See hotspots and anomalous areas
  - Filter by time, risk level, or zone type

- **Alerts & Incidents**
  - Alerts inbox with:
    - Priority / risk level
    - Type (loitering, suspicious hotspot, reliability issues)
  - Incident management:
    - Create from alerts
    - Assign to officers
    - Escalate / resolve incidents
    - View full audit trail

## Non-Goals for v1

- Full analytics / reporting suite
- Complex admin UI for multi-campus productization (can be added later)
