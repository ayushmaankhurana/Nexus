# Frontend Shared

## Purpose

Shared code and design system for mobile app and web dashboard.

## Contains

- TypeScript types / DTOs that mirror backend contracts
- Design tokens (colors, spacing, typography)
- Shared UI components (buttons, form fields, etc.)
- Utility hooks (API clients, auth helpers)

## Non-Goals

- Page-level components specific to mobile or dashboard
- Business logic (kept in backend and feature-specific frontends)
